# MUXIA NAME CLEARANCE V1

Status: INTERNAL CODENAME ALLOWED / PUBLIC BRAND HOLD
Date: 2026-08-26
Scope: preliminary web/IP/domain collision screening only; not legal advice and not a formal trademark clearance opinion.

## Verdict

`MUXIA` may continue as the **internal canonical codename** for the Proxima-successor project. It is **not cleared as a public trademark/product brand**.

Public-brand promotion is blocked pending formal trademark/domain clearance in the intended jurisdictions/classes.

## Findings

1. `Muxía` is an established municipality/place name in Galicia, Spain, with long-standing public use.
2. `muxia.com` is registered/resolving and is associated in public web results with Concello de Muxía contact usage. It is not available as a clean primary `.com` assumption.
3. Public web/trademark search surfaced multiple entities using `Muxia Technology Co., Ltd.` in China, including owners of unrelated Class 009 marks. This does not prove a conflicting `MUXIA` software mark, but it creates naming crowding.
4. A separate US mark `MUX` owned by Mux, Inc. was published for opposition on 2026-08-04 in International Class 042 for SaaS/PaaS AI-powered video/audio workflow services. Because MUXIA begins with/contains `MUX` and MUXIA is intended for AI/browser/software infrastructure, similarity review by trademark counsel would be prudent before public commercial use.
5. Exact-word public web search did not surface a clearly matching registered US/EU/WIPO software mark `MUXIA` in the sources checked. Absence in this preliminary search is **not** evidence of legal availability.
6. `MUXIA TYNLAN` appears registered in China in Class 003 (cosmetics/incense-related goods), which is commercially remote from MUXIA's intended software/runtime use but confirms that the word is not globally unique.
7. Patent search surfaced inventors/persons named `Muxia`, not an obvious blocking patent titled/claimed around the MUXIA software name. Product names are primarily a trademark/domain issue; patents protect inventions/claims rather than reserving a product word by itself.
