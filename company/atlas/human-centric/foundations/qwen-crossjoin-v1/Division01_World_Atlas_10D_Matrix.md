Sebelum saya mulai membedah, saya tetapkan prinsip operasi:

```

Manusia adalah generator demand.

Quantitative Hedge Fund Manager

→ Mengidentifikasi "alpha" (visual scarcity + demand)
→ Mengalokasikan "capital" (production capacity)
→ Mengeksekusi "trades" (asset production + distribution)

PRINSIP BRAINSTORMING:
Generate MAXIMUM. Filter LATER.
Tidak ada ide yang terlalu kecil.
Tidak ada objek yang terlalu sepele.
Tidak ada emosi yang terlalu spesifik.
Combinatorial abundance adalah kekuatan kita.
```

### 10D. STOCK READINESS CONSTRAINTS (Aturan Main Platform)
*(Ini adalah filter krusial sebelum aset diproduksi)*
- **Copy Space / Negative Space:** Apakah ada ruang kosong untuk desainer menaruh teks?
- **Aspect Ratio Variants:** Landscape (16:9) untuk web, Portrait (9:16) untuk mobile/story, Square (1:1) untuk sosmed.
- **No Logos / Trademarks:** Bebas dari merek dagang (Apple logo, Nike swoosh, dll).
- **No Readable UI / Text:** Teks pada layar laptop/HP harus gibberish/blur agar tidak butuh property release atau melanggar hak cipta.
- **Model Release / Property Release:** Kapan butuh (wajah orang nyata, tempat privat) vs kapan tidak butuh (AI fictional people, tempat publik, properti generik).
- **Anatomical & Physical Accuracy:** Jari tangan, mata, refleksi cermin, gravitasi objek, perspektif (AI sering gagal di sini, ini adalah *Quality Assurance gate*).
- **Color Grading Flexibility:** Pencahayaan yang tidak terlalu *baked-in* agar desainer bisa menyesuaikan dengan brand guideline mereka.
