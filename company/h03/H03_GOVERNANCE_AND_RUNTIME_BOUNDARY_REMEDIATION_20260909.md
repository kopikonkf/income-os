H03 must survive thousands of products, multiple browser shards, future VPS moves and changing providers. Opportunistically reusing any active browser profile or collapsing independent review into Founder QC creates hidden state and authority leaks that do not scale.

```text
  -> explicit product release/publication authorization

```

## Browser boundary

H03 owns dedicated host-local Knowledge/Growth/Commerce profile bindings. Durable canon stores only sanitized binding identity/state, never profile paths, cookies, tokens, credentials or session bytes.
