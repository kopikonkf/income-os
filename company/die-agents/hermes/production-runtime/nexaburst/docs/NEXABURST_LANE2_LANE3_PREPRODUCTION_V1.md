## Lane-2: Object Atlas -> Premium Semi-Realistic

Engine ID: `NEXABURST-LANE2-OBJECT-PSR`

The source universe remains Object Atlas. A concept that already exists in WC-L0 can be reused in PSR because the semantic identity includes the expression lane.

Identity example:

- WC: `NBWC-C123...`
- PSR: `NBPSR-C123-PSR-L0`

PSR-L0 is not "watercolor with a filter changed". It carries a different buyer utility and visual contract: premium commercial hero / catalog / marketing illustration, realistic proportions, crisp contours, controlled texture, dimensional lighting, and product-like framing.

PSR-L1 is prepared as a future restricted expression for function/feature explanation. It is **not universal** and must never be generated merely to create a second near-duplicate.

## Lane-3: Human-Centric Scene Engine

Engine ID: `NEXABURST-LANE3-HUMAN-SCENE`

The engine follows the Cross-Join Matrix doctrine:

`Human x Activity x Object x Place x Time x Demographic x Emotion x Problem x Industry x Commercial Intent`

The full cross-product is a search space, not an inventory target.

### Family is not Lane

A **Family** is a demand/problem domain, for example:

- care/accessibility
- workplace operations
- small business/service economy
- education/reskilling
- household finance/life decisions
- home/living
- digital trust
- practical sustainability
- food service
- family transitions

A **Lane (LN)** is a reusable commercial/visual scene expression:

- HC-L0 Workflow In Context
- HC-L1 Service Interaction
- HC-L2 Guidance And Learning
- HC-L3 Decision And Planning
- HC-L4 Care And Support
- HC-L5 Maintenance Repair And Setup
- HC-L6 Access Mobility And Adaptation
- HC-L7 Digital Task And Assistance
- HC-L8 Team Collaboration And Operations
- HC-L9 Transaction And Exchange
- HC-L10 Safety Prevention And Compliance
- HC-L11 Life Transition And Small Milestone

Therefore production scaling is:

`Family x eligible LN x coherent 10D dimensions`

rather than "one niche = one permanent lane".

A family can reuse several LN expressions, while the same LN can be reused by many families.

## Object Atlas inside Human-Centric scenes

Object Atlas is not discarded. It becomes scene evidence.

A screwdriver in an isolated-object engine is a sellable design component.

In HC-L5 the same semantic object may become evidence for a believable repair task.

The human-centric scene compiler may reference one or more Object Atlas candidate IDs, but those objects must have a story function. Random props are forbidden.

## Deterministic production contract

`nexaburst-preproduction-compile.py` produces:

1. semantic asset ID
2. frozen commercial/scene contract
3. contract SHA-256
4. deterministic system prompt
5. deterministic provider prompt
6. prompt SHA-256
7. `dispatch_authorized=false`

No web AI is needed to generate a prompt per artifact.
