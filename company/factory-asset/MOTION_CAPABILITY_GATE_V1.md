# Motion Capability and Temporal Value Gate v1

Task: `FA-130`
Status: PASS
Date: 2026-09-04

Motion eligibility is evaluated from the commercial product expression, not the noun alone. A candidate must have complete evidence, a modeled temporal verb, meaningful visual change, and buyer utility that specifically depends on change over time. If a static equivalent communicates the same value, the result is `STATIC_ONLY`.

Outcomes:
- `MOTION_ELIGIBLE`: temporal change adds buyer value and motion production may proceed;
- `STATIC_ONLY`: the concept is better communicated as a static asset or motion adds only decoration;
- `RESEARCH`: evidence, utility, or temporal behavior is incomplete/unmodeled;
- `REJECT`: commercial relevance has already failed.

The gate never converts an existing static master into motion. Motion remains a semantic asset expression generated directly from a motion Blueprint/producer route.
