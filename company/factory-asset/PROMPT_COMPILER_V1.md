# Production Prompt Compiler v1

Tasks: `FA-335`, `FA-336`

The compiler treats prose provider prompts as deterministic execution artifacts, never as the source of semantic truth. Inputs are a validated Subject Specification plus a resolved Visual Requirement Spec produced from one versioned Production Preset.

Compilation order is stable: subject form -> essential components -> recognition anchors -> natural attributes -> spatial structure -> view -> rendering descriptors -> fidelity -> composition/background -> commercial-use requirements -> subject-integrity constraints -> negatives. The output hashes the Subject Spec, Visual Spec and exact provider prompt.

For `ISOLATED_OBJECT`, validation requires full subject visibility, a clean silhouette, no unrelated props, explicit background mode and negative protections for readable text, logo, trademark and watermark. Every essential component and recognition anchor must survive into the compiled prompt.

The compiler does not invent missing subject facts. Complex-subject enrichment is upstream cognition/subject-intelligence work. This separation lets downstream visual QA compare generated artifacts against the same durable requirements used to generate them.

No provider call, submission, publication or live-runtime mutation is performed by this compiler.
