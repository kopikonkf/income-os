# DIE-H01 Optional API Provider Bridge v1

Task: H01-142

Browser-native H01 providers remain primary. API providers are opportunistic supplemental capacity only. Mission Control remains scheduling authority. Production roles default DISABLED and require explicit enablement.

A supplemental provider must be CONFIGURED, HEALTHY, externally authorized, explicitly ENABLE H01_SVG_GENERATION, and declare TEXT_SVG or NATIVE_SVG. The Founder Console provider route exposes only non-sensitive state/capability/health. Canonical runtime starts with zero configured API providers. H01-142 performs no live provider connection, generation, spend, browser-lane replacement, submission, or publication.
